# B7A1: Advanced Problem Solving with TypeScript & OOP

## Description

This repository contains the completed assignment files for the TypeScript and Object-Oriented Programming task. It includes:

- `solutions.ts` — implementation of all required coding problems in a single file
- `blog-1.md` — blog post about `any` vs `unknown` and type narrowing
- `blog-2.md` — blog post about `Pick`, `Omit`, and DRY principles

## File Structure

- `solutions.ts`
- `blog-1.md`
- `blog-2.md`
- `README.md`

## How to Run


```bash
#firstly Install it once:
npm install -g tsx
```
If you want to compile and run the assignment code, use one of these commands:

```bash
# compile the TypeScript file
tsx watch solutions.ts

```

## Problem Summary

- **Problem 1:** Filter even numbers from an array
- **Problem 2:** Reverse a string
- **Problem 3:** Detect whether a value is a string or a number using type guards
- **Problem 4:** Return an object property safely with a generic helper
- **Problem 5:** Add a read status to a book object using an interface
- **Problem 6:** Implement `Person` and `Student` classes with inheritance and a detail method
- **Problem 7:** Find the intersection of two number arrays

## Notes

- All code is written in `solutions.ts` as required
- The blog posts are in separate Markdown files
- The assignment does not include `console.log` statements in the final solution functions
